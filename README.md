# Kiehl Lab website

Website of the Kiehl Laboratory (principal investigator Kent A. Kiehl, PhD; Mind Research Network and University of New Mexico).
Planned address: **https://kentkiehl.com** (and later, optionally, kentkiehl.com).

It uses the open-source site framework that Tor Wager built for the [CANlab](https://torwager.github.io/canlab/) and
[Jakubzick Lab](https://claudjak.github.io/Jakubzick_lab/) sites (this repository started as a copy of
`claudjak/Jakubzick_lab`): a static site with a searchable, tagged publication database, reference export, a
collaborator map, bibliometrics, and an automated daily search for new papers. Content was carried over from the
WordPress site kentkiehl.com and from the CV of November 2026.

- **Static site** in `site/` (no build step for the HTML; JSON data and pre-rendered paper pages are generated by `pipeline/build_site.py` into `site/data/` and `site/papers/`).
- **Data** as plain JSON in `data/`:
  `papers.json` (bibliography: 284 articles, 9 chapters, 2 books and one retraction notice from the CV), `people.json` (lab and former trainees),
  `research.json` (research themes), `cv.json` (education, positions, honors, service, metrics, research history),
  `media.json` (podcasts, TV, lectures, press), `highlights.json` (the six home-page highlight slides), `lsrp.json` (the LSRP page: dedication, downloads, scoring, key papers, translations, and citation counts by country and year from OpenAlex, refreshed on Mondays by `scripts/lsrp_refresh.py`; to show a photo of Rick Levenson, add `site/assets/img/rick-levenson.jpg`), `treatment.json` (the Treatment page: three trials, from the research statement of Nov 2026), `books.json`, `resources.json`, `news_posts.json` (announcements),
  plus `candidates.json` / `screened.json` written by the daily search and `news.json` by the news search.
- **Tags** on three axes (`pipeline/taxonomy.json`): topic, approach, article type. The first pass was made from titles by `scripts/tag_by_rules.py`; edit tags by hand in `data/papers.json` (set `"tag_source": "hand"` so the rules never overwrite them).
- **Daily workflow** (`.github/workflows/daily.yml`): fills in abstracts from PubMed for the CV records (`scripts/enrich.py`), searches PubMed (and OpenAlex) for new papers, LLM-tags candidates into a review queue, refreshes citation counts, rebuilds and deploys.
- **News** every two days (`.github/workflows/news.yml`): Google News RSS, optional LLM relevance filter.
- **Hero graphic** (`site/assets/hero.js`): the mobile MRI truck drives around a map of the United States following the cursor (or touring by itself); at each city, mid-sagittal "scans" pop out in bubbles. An illustration, not a record of collection sites.
- **Highlights carousel** on the home page: six slides from `data/highlights.json`. Each slide shows an original illustrated panel unless it has `"img": "<file in site/assets/img>"` (plus optional `"credit"` and `"img_alt"`), in which case the photo fills the panel. Only use images you have the right to publish.

## Things still to add by hand

- **Photos**: put a portrait at `site/assets/img/kent-kiehl.jpg` (it appears automatically on the Biography page) and set `"img": "kent-kiehl.jpg"` for the first entry in `data/people.json`. Lab members' photos go in the same folder with `"img"` set on their entries. Book covers: add the image file and `"img": "<file>"` to the entry in `data/books.json`.
- **Research text** in `data/research.json` is a draft written from the CV; edit freely.
- **Google Scholar link / OpenAlex id**: add the Scholar profile link in `site/assets/layout.js` (footer) and set the repository variable `KIEHL_OPENALEX_AUTHORS`.
- **Scale files** on the Resources page still link to kentkiehl.com; copy them into `site/assets/files/` before retiring the WordPress site.

## Local use

```bash
pip install -r requirements.txt
python3 -m pipeline.build_site                 # writes site/data, site/papers, feed.xml, sitemap.xml
(cd site && python3 -m http.server 8765)       # http://localhost:8765
```

```bash
python3 scripts/import_cv.py cv.html           # rebuild papers.json from a new CV (pandoc cv.docx -t html --wrap=none -o cv.html); keeps tags and abstracts
python3 scripts/tag_by_rules.py                # re-run the first-pass title tagging on untagged records
python3 -m scripts.enrich                      # abstracts from PubMed (needs network)
python3 -m pipeline.run_daily --days 30 --dry-run
python3 -m pipeline.approve --list             # review queue;  python3 -m pipeline.approve <id> [<id>...]  promotes candidates
```

## One-time setup on GitHub

1. Create a public repository (e.g. `kiehl-site`) and push this folder to its `main` branch.
2. Run `python3 scripts/set_site_url.py <github-username> kiehl-site`, then `python3 -m pipeline.build_site`, and push again.
3. **Pages**: Settings → Pages → Source "GitHub Actions". The daily workflow deploys `site/`.
4. **Variables** (Settings → Secrets and variables → Actions → Variables): `KIEHL_SITE_URL` (the site address), `KIEHL_CONTACT_EMAIL` (polite-pool email for PubMed/OpenAlex), optionally `KIEHL_OPENALEX_AUTHORS` and `KIEHL_LLM_MODEL`.
   **Secrets** (optional): `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` for tagging new papers and filtering news; without a key the daily search still runs and queues untagged candidates.
5. **kentkiehl.com** (optional, later): `python3 scripts/set_site_url.py --domain kentkiehl.com <github-username> kiehl-site`, set the custom domain under Settings → Pages, and point the domain's DNS at GitHub Pages. The donation page on the WordPress site would need a new home first.
6. **Analytics** (optional): paste a Cloudflare Web Analytics token into `cfAnalyticsToken` in `site/assets/config.js`.
